# Sistema de Banco de Dados para Clínica Odontológica

## Sobre o projeto

Projeto de banco de dados relacional desenvolvido em SQL para o gerenciamento de uma rede de clínicas odontológicas.

O projeto foi desenvolvido como atividade acadêmica, com foco na criação, estruturação e consulta de um banco de dados relacional.

## Objetivo

O objetivo do projeto é desenvolver uma estrutura de banco de dados capaz de organizar informações relacionadas a:

- Clínicas
- Funcionários
- Dentistas
- Recepcionistas
- Pacientes
- Convênios
- Consultas
- Tratamentos
- Pagamentos
- Fornecedores
- Equipamentos

## Estrutura do banco

O banco de dados foi desenvolvido utilizando tabelas relacionadas por meio de chaves primárias e estrangeiras.

Entre as principais entidades estão:

- `CLINICA`
- `FUNCIONARIO`
- `CONVENIO`
- `PACIENTE`
- `RECEPCIONISTA`
- `DENTISTA`
- `TRATAMENTO`
- `CONSULTA`
- `PAGAMENTO`
- `FORNECEDOR`
- `EQUIPAMENTO`
- `UTILIZA`
- `REQUER`

## Consultas SQL

O projeto possui consultas utilizando diferentes recursos da linguagem SQL, incluindo:

- `SELECT`
- `JOIN`
- `WHERE`
- `ORDER BY`
- `GROUP BY`
- Funções de agregação
- `HAVING`
- Subconsultas

As consultas foram utilizadas para obter informações sobre consultas, pacientes, tratamentos e desempenho dos dentistas.

## Arquivos

| Arquivo | Descrição |
|---|---|
| `ddl.sql` | Criação das tabelas, chaves e relacionamentos do banco |

| `Trabalho Banco de Dados.pdf` | Documentação do projeto acadêmico |

- SQL

- Modelagem de Dados
